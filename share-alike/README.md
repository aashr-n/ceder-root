# share-alike

Material adapted from share-alike sources, such as Wikipedia, goes here and nowhere else.

- Licence: CC BY-SA 4.0 (see `LICENSE`).
- A share-alike source's text may be copied only into this folder, never into `bank/`. An adaptation must stay CC BY-SA, so it can't sit in the CC BY bank.
- Each file must carry the source's attribution: the title, a link to the original, and the licence name.
- This folder is empty for now.

See the repository's `README.md` for the rules and `sources/` for which sources are `copy-share-alike`. Not legal advice.
